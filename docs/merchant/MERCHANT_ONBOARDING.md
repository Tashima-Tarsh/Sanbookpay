# Merchant Onboarding

Every merchant receives an independent login and dashboard. The onboarding process is initiated by the Platform Owner through the Create Merchant wizard.

## Steps

1. Platform Owner creates the merchant with business identity details
2. Merchant ID is auto-generated (SBM-XXXXXXXX)
3. Merchant owner account is created with a secure activation invitation
4. Merchant owner sets password via one-time activation link (never plaintext)
5. MFA enrollment is completed
6. Pricing plan is assigned
7. Payment capability is configured (receiving banks, UPI routes, providers)
8. Merchant controls are set (API access, webhooks, payment links, etc.)
9. Merchant is activated and receives dashboard access
