# Merchant Configuration

Merchants can configure the following settings within their approved capabilities:

## Receiving Bank Settings

View approved receiving accounts, VPAs, bank connection status, transaction feed, settlement status, reconciliation results.

## API Credentials

Create, rotate, revoke API keys with scopes and rate limits.

## Webhook Configuration

Register callback URLs, review signing configuration, inspect deliveries.

## Routing Preferences

Select from approved routes where permitted by Platform Owner.

## Security

- MFA enrollment
- Session management
- IP restrictions (where configured)

Changes affecting bank ownership, live routing, credentials, or payment collection eligibility may require Platform Owner approval.
