# Merchant Dashboard

Each merchant receives an independent dashboard with its own settings, API credentials, bank/payment configuration, dynamic payment links, payment history, webhook URL, staff users, and integration controls.

## Navigation

1. Dashboard Overview — Merchant health summary
2. Create Payment Link — Amount-only payment link generation
3. Dynamic QR Payments — UPI QR code payments
4. Payment Orders — View and manage payment orders
5. Transactions — Transaction history
6. Receiving Bank Settings — View approved receiving accounts
7. Receiving UPI IDs — View approved VPAs
8. Routing Preferences — Configure permitted routing preferences
9. API Credentials — Manage API keys
10. Webhook Configuration — Register callback URLs
11. Gaming Wallet Integration — View wallet balances
12. Settlement Reports — View settlement data
13. Reconciliation — View reconciliation results
14. Payment Diagnostics — Investigate payment issues
15. Pricing & Billing — View pricing and invoices
16. Staff & Users — Manage merchant staff
17. Security Settings — Configure security
18. Reports — Generate reports
19. Support — Contact support
20. Merchant Profile — View and update profile

Merchant changes affecting bank ownership, live routing, credentials, or payment collection eligibility may require Platform Owner approval.
