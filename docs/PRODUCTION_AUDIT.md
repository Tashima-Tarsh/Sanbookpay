## What Is DONE — VERIFIED

### Core Payment Engine (35/35 test suites passing)
- **Payment state machine**: `CREATED → PENDING → VERIFIED_SUCCESS → MERCHANT_NOTIFIED` + `FAILED`, `EXPIRED`, `CANCELLED`, `UNKNOWN`
- **Exclusive single-active-slot FIFO queue**: Exactly one ACTIVE/PROCESSING session per receiving VPA; others serialized in QUEUED
- **Dual server-authoritative timers**: 5-minute ACTIVE window + 30-second PROCESSING window
- **Pure SVG QR engine**: ISO/IEC 18004 compliant `upi://pay` QR codes, zero external API
- **Integer paise arithmetic**: No floating-point for money
- **Double-entry ledger**: Chart of accounts, journal, trial balance
- **HMAC-SHA256 webhook verification**: Raw-body constant-time comparison
- **AES-256-GCM credential vault**: Encrypted at rest
- **Fraud detection & auto-banning**: Browser fingerprinting, instant ban
- **Refunds**: Full refund lifecycle with ledger liabilities
- **Settlements**: Bank credit confirmed, settlement entries, three-way reconciliation
- **Split settlement** (just added): Platform fee + GST + merchant share per transaction
- **Auto-refund** (just added): Instant refund for FAILED/EXPIRED/CANCELLED sessions
- **UTR manual verification**: Customer submits UTR → instant SUCCESS + webhook callback
- **Rate limiting**: 1000 req/min per IP (gaming-ready)
- **Structured logging**: NDJSON output
- **Graceful shutdown**: SIGINT/SIGTERM handling

- No shadcn/ui, no Tailwind design system

- No NestJS or Fastify (native Node.js http module used)
- No TypeScript for application code (only devDependencies)

- **Reverse proxy (Caddy/Nginx)**: Not configured
- **OpenTelemetry/Prometheus/Grafana**: Not present
- **CI/CD**: Not present

### 4. Testing (MEDIUM)

- No k6 load testing
- No contract tests against real provider APIs (blocked by missing credentials)

### 5. Documentation (LOW — mostly exists)
